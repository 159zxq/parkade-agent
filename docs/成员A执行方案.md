## 2. 你的开发任务卡（W1–W4）

### A1：Agent 骨架（W1）
- `agent/graph.py`：`create_react_agent` + `SqliteSaver`（`langgraph-checkpoint-sqlite`），`thread_id` = 前端会话 id；
- `agent/prompts.py` system prompt 写死五条边界：①费率解释走知识库附引用；②费率计算走工具；③识别失败引导重拍；④域外拒答不编造；⑤先结论后依据；
- 验收：对 stub 能完成"查车位→入场"两轮对话，重启进程后历史不丢。

### A2：双通道视觉（W2 上半）
- `agent/vision.py`：`recognize_plate` 工具内部 `asyncio.gather` 并行 HyperLPR3 + 视觉 API，单通道超时 4s；
- 仲裁按契约矩阵五分支；`sha256` 图片哈希缓存（重复抓拍直接命中，标 `cached:true`）；
- 验收：normal 变体 `both_agree`；blur 变体 `vlm_only`；occluded 变体 `failed`——**三变体现场跑一遍截屏存档**（测试报告素材）。
- HyperLPR3 装不上 → W2 内触发 fallback：OpenCV 模板匹配自合成车牌（图是我们自己画的，可控），再不行单通道 VLM（仲裁矩阵天然兼容）。

### A3：工具全量 + RAG 接入（W2 下半）
- `agent/tools.py` 五工具照契约工具表实现（mock 客户端统一 `httpx` + 错误码转人话）；
- RAG 接入：调 C 的 `retrieve()`，拼上下文，引用格式化（章节号 + chunk id）；
- 验收：端到端剧本 8 步（演示脚本前半）命令行全通。

### A4：命中率冲线兜底（W3）
- 周中运行 `python kb/eval_rag.py`：<90% → 你接管调优（C 转测试执行，按预案走，不背锅）；
- 调优优先级：补语料 → FAQ 加口语化条目 → 切分规则 → top-k 调参；**≥95% 后冻结**，把调优过程写进测试报告的"局限性与优化"。

### A5：前端与全量测试（W4）
- `app/streamlit_app.py`：三块布局（聊天+引用折叠 / 抓拍演示+仲裁徽章 / 车位看板）；`st.session_state` 存 thread_id；
- 全量测试执行：mock（B 的表）、仲裁矩阵（你的）、RAG 60 条（C 的脚本）、多轮/拒答（你的）、延迟 20 次预热前后（你的）、持久化（重启进程验证）、一致性（rates vs 语料）、异常流（kill mock、断网各一次）；
- 所有原始数据（截图、日志、命中率输出）存 `docs/测试证据/`，W4 末统一进测试报告。

### A6：冻结与答辩（W5）
- 周一 freeze：只修 bug 不加功能；`scripts/prewarm.py` 把演示相机三变体 + 常用问题跑一遍；
- 彩排 ≥2 次（含断网演练）：按演示脚本 8 步走，录屏一份备用；
- 答辩分工：B 讲 mock 与虚拟时钟/测试记录，C 讲知识库规模与命中率，你讲架构 + RAG 原理 + 双通道 + 现场操作；现场调 bug 环节只你来。

## 5. 你的 AI 档案重点（答辩的"AI 辅助开发"叙事在你这里）

最有说服力的记录类型：**AI 生成原始版 → 你发现的问题 → 修正 diff → 验证数据**。例如：
- AI 写的仲裁逻辑把"不一致"错误地以 VLM 为准 → 你改为 OCR 优先（贴 diff + 契约条款）；
- AI 写的缓存没算 variant 维度（blur/normal 同图命中同一个缓存）→ 你加 variant 进哈希；
- AI 给的 embedding 调用没分批 → 建库报 400，你改写分批 + 重试。
这类"人工把关"记录 > 10 条，档案列满分叙事就成立了。
